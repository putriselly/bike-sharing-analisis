# Proyek Analisis Data: Bike Sharing Dataset

Proyek ini menganalisis data penyewaan sepeda (Bike Sharing Dataset) untuk menjawab pertanyaan:

1. Apakah kondisi cuaca memengaruhi jumlah penyewaan sepeda?
2. Pada musim apa jumlah penyewaan sepeda paling tinggi?

## Cara Menjalankan Dashboard

1. Install library yang dibutuhkan:

pip install -r requirements.txt


2. Masuk ke folder dashboard:

cd dashboard

3. Jalankan dashboard:

streamlit run dashboard.py

4. Dashboard akan terbuka di browser.
